# Frontend de Alzada

Aplicación Angular del marketplace, el panel de constructoras y el portal del comprador. La forma de ejecutar el proyecto completo, las cuentas de demostración y las variables de entorno están en el [README de la raíz](../README.md).

Para trabajar solo en la interfaz, con la API ya escuchando en el puerto 8080:

```bash
npm ci
npm start
```

El servidor de desarrollo queda en http://localhost:4200 y reenvía `/api` y `/sitemap.xml` a la API.
